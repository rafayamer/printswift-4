# Invoice preview integration

The browser preview now exposes A4 and 80 mm invoice previews, with F7/F8 keyboard shortcuts. Newly saved demo orders store exact integer-paisa totals, advances, discounts and rates. Older demo records cannot be reprinted because their original discounts were not preserved.

This is a development preview only. No FBR submission occurs, and invoices are marked NOT FBR VERIFIED. The native Tauri application remains separate and requires integration and testing.
